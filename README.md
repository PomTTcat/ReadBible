# ReadBible · 经文与脉络

圣经人物、地点与事件的交互资料库。本仓库目前是本地实验原型，尚未发布网站，也未锁定正式框架。

## 运行

需要 Node.js 16 或更高版本，无需安装依赖。

```sh
npm run dev
```

打开终端显示的地址，默认是 http://127.0.0.1:4173 。请通过 HTTP 打开，不能直接双击 HTML 文件。

```sh
npm test
npm run build
node scripts/serve.mjs --dist
```

构建结果在 `dist/`，可部署到 GitHub Pages 等静态托管；链接使用 hash 路由，兼容仓库子路径，无需后端重写规则。此轮只生成本地项目。

## 目前可体验

- 书卷 → 章节目录 → 章节页面；首批收录四卷目录，八章有样本，其余明确标为待整理。
- 创世记 4章：共用人物与家庭资料；连接处的加减号折叠分支，人物点击查看出处，再跳到全局图定位，可返回原章节。
- 地图：四个叙事节点，拖动时间轴、点击节点或左右箭头，同步改变城市、区域状态及事件说明，可跳回对应章节。
- 创世记 5章：亚当至挪亚及三个儿子的谱系、本章结构、阅读说明与经文来源；同名人物分开记录。
- 全局人物图目前包含创世记 4、5章样本，不代表完整圣经族谱。章节图按人物及关系 ID 筛选，全局图复用全部已录入关系。

## 数据与展示的边界

```text
index.html                  页面入口
src/
  app.js                    目录、章节与路由
  data.js                   共用数据读取
  dom.js                    DOM 工具
  components/
    genealogy.js            可复用族谱组件
    event-map.js            可复用地图与时间轴组件
  styles.css                展示样式

data/                       核心资料：不依赖图表库
  catalog.json              书卷、分类、章节数量
  chapters.json             章节说明、人物 ID、图表 ID
  people.json               稳定人物 ID 与经文引用
  families.json             父母组合、子女与依据
  places.json               地点与经文引用
  events.json               事件、地点关联与对应章节

presentation/               展示配置：通过 ID 引用核心资料
  figures.json              图表类型、根人物、展开状态、事件序列
  maps.json                 示意轮廓、标记位置、注释与事件状态
scripts/                    本地静态预览与构建
tests/                      资料引用、谱系循环与地图状态一致性检查
```

同一图表 ID 可被多个章节引用。新增章节时在 `data/chapters.json` 添加记录，引用现有或新的图表配置；人物及事件不需要复制到页面代码。更换展示框架时保留 `data/`，重写组件与相应配置适配。

当前家庭记录按父母组合组织；妻、妾等关系应按来源标明。只列一位亲本表示当前样本未收录另一位，不表示其未知或不存在。相同名字使用不同 ID，不能自动合并。正式资料模型还需要逐条证据、不确定性与版本管理，后续再完善。

## 地图与资料范围

地图是**叙事关系示意，非真实疆界**，节点间距不表示距离。时间轴按四个事件等距排列，不是连续历史年份，也不推演节点之间的疆界。区域纹理表示“此时已发生陷落事件”，不代表此后的精确统治范围。地图注释表示当前事件，虚线是注释指引，不是军队路线。

示例资料依据所标的经文章节整理，未收录完整经文，尚未进行正式学术资料审核。后续需要引入有来源的历史地理数据、年代范围和证据分级；显示坐标与真实地理坐标应分开保存。

技术讨论与实验结果持续记录在[技术讨论与实验记录](技术讨论与实验记录.md)。

已处理章节见[章节处理进度](docs/章节处理进度.md)。进度以章节数据里的 `processing` 字段为准，运行 `npm run progress` 或 `npm run build` 自动更新记录。“已做原型”和“已审核”分别记录。

创世记 6章使用器物尺寸图，数据保存在 `data/objects.json`，图像来源与许可在 `data/assets.json`。长宽高采用经文中的肘数；1690年版画作为独立艺术参考，来源见图片署名。

创世记 1章新增七日配图，叙事数据在 `data/sequences.json`。第七日单独标明来自创2:1–3；七张图片的作者、来源及公共领域标记记录在 `data/assets.json`。
